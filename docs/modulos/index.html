Ficha de cada módulo

Para que las páginas sean parejas, cada módulo se documenta con estas secciones:

  1. Para qué sirve: el proceso del depósito que resuelve.
  2. Pantallas: qué se puede hacer en cada una.
  3. Estados y reglas: ciclo de vida del documento y validaciones.
  4. Efecto sobre el stock: qué movimientos genera.
  5. Importación y exportación: columnas de la plantilla.
  6. Rutas y permisos: rutas del catálogo.
  7. Tablas: tablas que lee y escribe.
