Administración

Panel admin

Aplicación de administración de la instalación: python admin.py, en http://localhost:5001/admin.

Lo básico

  • Sus usuarios están en taurus_admin.admin_usuarios, separados de los usuarios del WMS (taurus_admin.usuarios).
  • Roles del panel: SUPERADMIN y ADMIN. Los parámetros de tenants, los tokens de API y la sección de intercambio son solo para SUPERADMIN.
  • Usa su propia cookie de sesión, taurus_admin_session.
  • El primer usuario se crea con el ejecutable de superusuario.
