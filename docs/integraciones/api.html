Integraciones

API REST

API JSON bajo /api/v1 para que sistemas externos consulten catálogos y stock y registren recepciones. Código en modules/api.py.

Autenticación

Cada tenant tiene un token. Lo genera un SUPERADMIN desde el panel admin (/admin/parametros/<tenant>/api-token) y se guarda como hash SHA-256: el token en claro se muestra una sola vez. Se envía en cada pedido:

Authorization: Bearer <token>

Todos los endpoints quedan acotados al tenant del token. El límite es de 60 pedidos por minuto por dirección IP.

Errores

Siempre con el formato { "ok": false, "error": "mensaje" }.

CódigoMotivo
400Parámetros inválidos o faltantes.
401Falta el encabezado Authorization o el token es inválido.
403El tenant está desactivado.
404Recurso no encontrado.
409Conflicto de estado (por ejemplo, cerrar una recepción que no está Abierta).
500Error interno.

Consultas (GET)

EndpointDescripciónParámetros
/api/v1/materialesLista de materiales.q, activo, limite
/api/v1/materiales/<codigo>Material por codigo o codigo_barras.—
/api/v1/ubicacionesCatálogo de ubicaciones.q, tipo, limite
/api/v1/stockStock por posición.ubicacion, material, lote, tipo_stock, todos, limite
/api/v1/recepcionesRecepciones, cabecera y totales.estado, proveedor, limite
/api/v1/recepciones/<numero>Recepción con sus ítems.—
/api/v1/pedidosPedidos.estado, limite
/api/v1/omcsÓrdenes de movimiento.estado, limite
  • limite: 100 por defecto, entre 1 y 500.
  • En /stock, material acepta codigo o codigo_barras.
  • En /stock, todos=true (default) devuelve solo filas con saldo distinto de cero; todos=false las trae todas.

Escritura (POST)

EndpointDescripción
/api/v1/recepcionesAlta de recepción con sus ítems.
/api/v1/recepciones/<numero>/agregar-itemAgrega o actualiza un ítem en una recepción Abierta.
/api/v1/recepciones/<numero>/cerrarCierra la recepción: mueve el stock y genera una OMC Pendiente (devuelve numero_omc).
/api/v1/omcs/<numero>/confirmarConfirma una OMC de recepción: el stock pasa de Entrando a Disponible. No aplica a las OMC de pedido.

Alta de recepción

{
  "proveedor_codigo": "PROV001",
  "ubicacion_recep_codigo": "R-01",
  "ubicacion_destino_codigo": "A-01-01",
  "observaciones": "Compra 12345",
  "items": [
    {
      "material_codigo": "MAT001",
      "cantidad": 100,
      "lote": "L2024-01",
      "fecha_vencimiento": "2026-12-31",
      "tipo_stock": "Libre Venta"
    }
  ]
}

Genera el número REC-AAAA-NNNNN y un contenedor. Los ítems inválidos (material inexistente o inactivo, cantidad menor o igual a cero) se informan en errores y el resto se inserta. Si ninguno es válido, se revierte todo y responde 400.

Ejemplo

TOKEN="<token-del-tenant>"
curl -s http://localhost:5000/api/v1/materiales -H "Authorization: Bearer $TOKEN"
