Primeros pasos

Instalación

Cómo dejar el WMS y el panel admin corriendo en una máquina de desarrollo.

Requisitos

  • Python 3.10 o superior (probado con 3.12).
  • MySQL 8 (recomendado), PostgreSQL o SQL Server. Ver Base de datos.
  • Los drivers de PostgreSQL (psycopg2-binary) y SQL Server (pymssql) ya están en requirements.txt.

1. Entorno y dependencias

python -m venv .venv
.venv\Scripts\activate          # Windows  (Linux/Mac: source .venv/bin/activate)
pip install -r requirements.txt

copy .env.example .env          # Windows  (Linux/Mac: cp .env.example .env)

Editar .env y cambiar los secretos y contraseñas. El detalle de cada variable está en Configuración.

2. Crear las bases de datos

# Genera y ejecuta el schema completo (admin + wms + intercambio) con datos iniciales
python generar_schema.py --engine mysql --execute --seed

Después de crear una base desde cero hay que registrar las migraciones existentes como aplicadas, para que el runner no intente ejecutarlas de nuevo:

python migrate.py --baseline
python migrate.py --db admin --baseline

Más detalle en Schema y migraciones.

3. Ejecutar

python app.py     # WMS   — http://localhost:5000
python admin.py   # Admin — http://localhost:5001/admin
