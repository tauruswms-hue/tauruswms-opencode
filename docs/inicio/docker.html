Crear el schema

El compose no crea las tablas. La primera vez hay que generar el schema y registrar las migraciones, dentro del contenedor o desde la máquina local contra el MySQL del compose (ver Schema y migraciones).

Es un compose de desarrollo. Fija APP_ENV=development, conecta con el usuario root de MySQL y usa secretos por defecto si no se definen SECRET_KEY, ADMIN_SECRET_KEY y SECRET_SALT. Las conexiones salen de conexiones.docker.json, que se monta en los contenedores como conexiones.json: si se cambia MYSQL_ROOT_PASSWORD, hay que cambiarla también en ese archivo. No usarlo tal cual en producción; ver Puesta en producción.
