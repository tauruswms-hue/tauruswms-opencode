taurus_wms

Base operativa: maestros, stock, recepciones, pedidos y movimientos.

Se crea después de taurus_admin.

El script borra la base si ya existe. Empieza con DROP DATABASE IF EXISTS taurus_wms. Sirve para una instalación nueva; sobre una base en uso, se pierden todos los datos.

Ejecutar

Desde la raíz del proyecto, con un usuario de MySQL que pueda crear bases:

mysql -u root -p -e "source docs/migrations/create_wms_mysql.sql"

Después, registrar las migraciones como aplicadas:

python migrate.py --db wms --baseline

Datos iniciales

El script solo carga las clases de pedido: Venta, Reposicion, Muestra y Devolucion. El resto de los maestros se carga desde la aplicación o por importación.

Archivo: docs/migrations/create_wms_mysql.sql (508 líneas). Lo genera modules/schema_generator.py; no se edita a mano.
