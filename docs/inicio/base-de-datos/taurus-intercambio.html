taurus_intercambio

Base de la interfase con sistemas externos.

Solo hace falta si se usa Intercambio.

El script borra la base si ya existe. Empieza con DROP DATABASE IF EXISTS taurus_intercambio. Sirve para una instalación nueva; sobre una base en uso, se pierden todos los datos.

Ejecutar

Desde la raíz del proyecto, con un usuario de MySQL que pueda crear bases:

mysql -u root -p -e "source docs/migrations/create_intercambio_mysql.sql"

Después, registrar las migraciones como aplicadas:

python migrate.py --db intercambio --baseline
