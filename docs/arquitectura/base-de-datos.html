Base de datos

Motores soportados, las tres bases del sistema y cómo se resuelven las conexiones.

Motores

No hay ORM: el código escribe SQL y lo adapta a cada motor con modules/sql_dialect.py. El motor se elige con DB_ENGINE (o DB_<BASE>_ENGINE por base).

MotorDB_ENGINEDriverPuertoUso
MySQLmysqlpymysql3306Default y recomendado.
PostgreSQLpostgresqlpsycopg25432Soportado.
SQL Serversqlserverpymssql1433Soportado.
SQLitesqlitesqlite3— Solo referencia: se genera el DDL, pero la aplicación no funciona sobre SQLite.

Por qué SQLite no es un runtime. El código usa marcadores %s y filas tipo diccionario; el driver sqlite3 no acepta %s.

Las tres bases

BaseContenidoDe dónde sale la conexión
taurus_adminUsuarios, tenants, roles, configuración. Variables DB_ADMIN_* del entorno.
taurus_wmsDatos operativos: maestros, stock, pedidos, recepciones. Tabla configuracion de taurus_admin; DB_* como respaldo.
taurus_intercambioInterfase con sistemas externos. Claves INTERCAMBIO_* de configuracion; DB_INTERCAMBIO_* como respaldo.

Conexiones

probar_conexion()Prueba una conexión con parámetros sueltos, sin tocar el pool.

Las tres usan un pool PooledDB (DBUtils), uno por combinación de motor y configuración, con hasta 20 conexiones.

conn.close() no cierra. Devuelve la conexión al pool (con rollback). Los pools se desarman con clear_config_cache() o cuando cambia la configuración.

Propagación de cambios de configuración

La configuración leída de la tabla configuracion se cachea y se relee cada CONFIG_CACHE_TTL segundos (30 por defecto). Si los valores cambiaron, se reinician el motor y los pools. Así llegan al proceso del WMS los cambios hechos desde el panel admin, que corre en otro proceso. Si la base admin está caída al refrescar, se conserva la última configuración conocida.

Reglas al escribir SQL

  • Nunca escribir backticks a mano. Los identificadores se entrecomillan con sql_quote(); los backticks de MySQL rompen el resto de los motores.
  • Usar los helpers de sql_dialect.py para lo que difiere entre motores: insert_ignore_sql(), upsert_sql(), limit_sql(), concat(), group_concat(), entre otros.
  • Marcadores %s y filas como diccionario.
  • Toda consulta operativa lleva el filtro de tenant. Ver Multi-tenancy.
