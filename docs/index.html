Taurus WMS

Sistema de gestión de almacenes (Warehouse Management System) multi-tenant, desarrollado en Flask.

Taurus WMS cubre el ciclo operativo de un depósito: maestros (materiales, ubicaciones, clientes, proveedores), recepciones, movimientos internos, pedidos, picking y despacho, con control de stock, auditoría de movimientos y reportes. Cada empresa (tenant) trabaja sobre sus propios datos.

Aplicaciones

AplicaciónPuertoPara qué
app.py5000WMS: la aplicación operativa.
admin.py5001Panel de administración, en /admin: tenants, usuarios, roles y parámetros.
schema_app.py5002Generador de schema con interfaz gráfica. Solo desarrollo.

Las tres comparten el mismo .env, el archivo de conexiones (conexiones.json) y la base administrativa taurus_admin.

Cómo buscar

  • En toda la documentación: el campo de la barra superior, disponible en todas las páginas. La tecla / lleva el cursor ahí.
  • En una sola sección: el campo de cada tarjeta del mapa de abajo, o la lupa que está junto al nombre de cada sección en el menú lateral.

Se puede escribir más de una palabra: aparecen los lugares donde están todas. No distingue mayúsculas ni acentos. Cada resultado lleva al título de la página donde está el texto. Con las flechas se recorren los resultados y Esc cierra la lista.

Mapa de la documentación

Cada página lleva su estado: Completa, Borrador (contenido parcial) o Pendiente (solo el esquema).

Cómo ampliar esta documentación

  1. Copiar docs/_plantilla.html a la carpeta de la sección que corresponda.
  2. Ajustar data-root y data-page en el <body>.
  3. Registrar la página en NAV, dentro de docs/assets/docs.js, con su estado. El menú lateral, este mapa y los enlaces anterior/siguiente se generan desde ahí.
  4. Regenerar el índice del buscador: python docs/generar_buscador.py. Hay que hacerlo también al cambiar el texto de una página existente.

Son páginas HTML estáticas: se abren directamente desde el disco, sin servidor ni paso de compilación.
