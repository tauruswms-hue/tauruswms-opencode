Primeros pasos

Datos de base

Los datos que se cargan una vez y después se usan en todas las operaciones: materiales, proveedores, clientes, ubicaciones, rutas y transportes.

Qué se administra acá

  • Materiales: lo que se recibe, almacena y despacha. Pueden tener código de barras, lote, vencimiento y presentaciones.
  • Proveedores: quién entrega la mercadería. Algunos materiales quedan asociados a un proveedor.
  • Clientes: quién pide los pedidos. Suele tener una ruta y un transporte habituales.
  • Ubicaciones, zonas y tipos de ubicación: dónde está la mercadería. Hay ubicaciones para recibir, para almacenar y muelles de salida.
  • Rutas y transportes: cómo se entregan los pedidos. Un transporte puede tener uno o más muelles asignados.
  • Clases de pedido, categorías y unidades: clasificaciones que se usan al cargar materiales y pedidos.

Cargar un dato nuevo

  1. Entrá a la pantalla correspondiente desde el menú lateral.
  2. Apretá Nuevo y completá los campos marcados como obligatorios.
  3. Revisá el código: es la forma en que el dato aparecerá en las otras pantallas y en las plantillas.
  4. Apretá Guardar. Si hay un error, el sistema indica qué campo revisar.

Buscar, editar y dar de baja

  • Usá el filtro o la búsqueda de la grilla para encontrar el registro. Podés ordenar las columnas apretando sobre el encabezado.
  • Editar permite corregir los datos. Si el registro ya se usó en operaciones, cambiá con cuidado los códigos: podrías perder la relación con trabajos anteriores.
  • Dar de baja no borra la historia: el dato deja de ofrecerse en los formularios nuevos, pero sigue visible en las operaciones ya hechas.

No des de baja un material mientras tenga stock, ni una ubicación que todavía contenga mercadería. Primero vaciala o mové el stock con un movimiento.

Importar desde una plantilla

Cuando hay muchos datos para cargar, las pantallas ofrecen descargar una plantilla en Excel o CSV.

  1. Apretá Descargar plantilla y completá las filas siguiendo las columnas de ejemplo.
  2. Apretá Importar y elegí el archivo.
  3. Leé el resultado: informa cuántas filas se crearon y detalla los errores por fila.
  4. Coregí sólo las filas con error y volvé a importarlas. No hace falta repetir las que ya se crearon.

Si el formulario pide un CUIT, escribilo con el formato 99-99999999-9 o los 11 números sin guiones; el sistema lo deja con guiones. Un CUIT con otro formato impide guardar el registro.

Exportar

El botón Exportar descarga el listado filtrado. Es útil para revisar los datos con el área administrativa o para preparar una importación posterior.

Si falta una opción

Algunas altas —por ejemplo crear una zona, definir un muelle o habilitar un tipo de ubicación para recibir— las hace el administrador del sistema. Si el formulario no te ofrece el dato que necesitás, consultalo antes de cargar la operación.
