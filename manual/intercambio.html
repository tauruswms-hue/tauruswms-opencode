Datos de otros sistemas

Cómo aplicar en el depósito los datos que llegan desde el sistema de gestión de la empresa.

Qué hace esta pantalla

El sistema de gestión envía altas, cambios y bajas de rutas, transportes, clientes, materiales y pedidos. Esos datos llegan pendientes de aplicar. Esta pantalla permite procesarlos, revisar los que dieron error y volver a intentarlos.

Procesar lo pendiente

  1. Entrá a Intercambio con sistemas externos.
  2. Revisá el contador de Pendientes.
  3. Apretá Procesar Pendientes.
  4. Leé el resultado: el registro cuántos datos se aplicaron y cuántos dieron error.

Los datos se aplican en un orden determinado: primero rutas y transportes, después clientes y materiales, y por último pedidos. No hace falta cambiar ese orden manualmente.

Revisar errores

Apretá el filtro Errores para ver los registros que no se pudieron aplicar. Cada fila muestra:

  • El tipo de dato y una referencia para identificarlo.
  • La acción que se intentó: alta, modificación o baja.
  • El estado y la cantidad de intentos.
  • Un mensaje con el motivo del error.

El mensaje de error es la pista más importante. Si dice que un código no existe o está repetido, revisá ese dato en el sistema de gestión antes de reintentar. Si dice que el CUIT no es válido, corregilo con el formato 99-99999999-9.

Reintentar

  • Reintentar Errores: vuelve a procesar todos los registros con error.
  • El botón de la fila repite uno solo. Es útil cuando corregiste ese dato puntual.

Si un error se repite después de corregirlo, informalo al administrador con el número de registro y el mensaje exacto.

Historial

Abajo de la pantalla hay un historial de ejecuciones con fecha, resultado, cantidad de registros procesados y errores. Sirve para confirmar si un dato ya se aplicó antes de volver a procesarlo.

Cuidados

  • No repitas «Procesar Pendientes» varias veces seguidas: esperá el resultado de cada ejecución.
  • Una baja de material o cliente no borra la historia: deja de ofrecerse en los formularios nuevos.
  • Un pedido que ya se está preparando no se borra automáticamente aunque llegue una baja desde el otro sistema.
